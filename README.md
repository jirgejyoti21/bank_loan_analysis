# Bank Loan Analysis Dashboard

## Project Overview

The Bank Loan Analysis Dashboard is a Business Intelligence project developed using Python, Jupyter Notebook, and Power BI. The project focuses on analyzing bank loan data to provide meaningful insights into loan performance, customer behavior, funding trends, and risk assessment.

The dashboard transforms raw loan data into interactive visualizations that help banks monitor loan applications, funded amounts, received amounts, interest rates, debt-to-income ratios, and loan status distribution.

---

## Objectives

- Analyze bank loan application data.
- Identify good and bad loans.
- Monitor loan funding and repayment performance.
- Visualize trends and patterns using interactive dashboards.
- Support data-driven decision making in the banking sector.
